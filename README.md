# FileNote

Notas para escritorio de la suite Razor. Gratis, sin cuenta: tus notas se guardan en tu equipo.

- Editor de texto enriquecido, carpetas y etiquetas, búsqueda rápida (Ctrl+K)
- Enlaces entre notas con `[[` y referencias inversas
- Dibujo a mano, imágenes y archivos adjuntos
- Exportar a PDF, Word y Markdown
- Copias de seguridad automáticas y actualizaciones automáticas

## Descargar

Última versión: [Releases](https://github.com/Eva-one01/FileNote/releases/latest)

## Desarrollo

```bash
npm ci
npm run dev        # interfaz en el navegador
npm run build && npm run electron
```

Publicar una versión: sube el número en `package.json` y lanza el flujo **Publicar** en Actions.
